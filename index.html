About Vehicle Dispatch Tracker

Transport order and fleet management application for logistics operations across Dammam, Riyadh, Jeddah, Makkah, Madinah, Rabigh, Yanbu, and Taif. Supports single and bulk order entry, fleet and address book registries, route mapping with Leaflet, order tracking with status history records, monitoring dashboards with charts, print and PDF reports, JSON/CSV/Excel export, audit logging, and password lock — all with offline persistence using SQLite via sql.js and IndexedDB.

External resources integrated: Leaflet for maps, CARTO and Esri tile layers, Geoapify for geocoding and routing, and sql.js for local SQLite database operations.
